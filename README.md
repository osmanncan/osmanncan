## 🏗️ Featured Engineering & App Architecture 
I don't just build user interfaces; I design secure, scalable, and offline-first full-stack architectures. Here is the technical blueprint of my recent production-grade mobile app:

* 🛡️ **Database & Auth (Supabase / PostgreSQL):** Implemented secure asymmetric encryption for authentication (Deep Links) and strict **Row Level Security (RLS)** in PostgreSQL to ensure absolute data isolation between users.
* ⚡ **Secure Serverless Backend (Deno Edge Functions):** Isolated critical business logic from the client. Deployed ultra-fast V8-powered Edge Functions to handle **RevenueCat webhooks** (validating Apple/Google payments server-side) and proxy **Google Gemini AI 1.5 Pro** requests (keeping API keys 100% hidden from the frontend).
* 💳 **Payment Infrastructure (RevenueCat):** Seamlessly managed In-App Purchases (IAP) and subscription lifecycles, accurately tracking free trials and secure renewals on the backend.
* 💾 **Offline-first Cache (Zustand + AsyncStorage):** Engineered a highly optimized offline-first experience. Global state is managed with Zustand and cached locally to minimize server requests, reduce cloud costs, and ensure app reliability even without internet access.
