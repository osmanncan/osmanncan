## 👨💻 About Me

I'm a mobile and frontend developer from Istanbul, focused on building fast, clean, and user-friendly apps. My main stack is **React Native (Expo)** and **React**, and I care deeply about smooth UX, real-world architecture, and writing code that actually ships.

- 📱 Primarily building with **React Native (Expo)** & **TypeScript**
- 🌐 Full-stack capable with **Next.js** on the web side
- 🗄️ Backend via **Supabase** (PostgreSQL + Auth + Edge Functions)
- 🎯 Interested in: animations, offline-first patterns, AI integration, design systems
- 🌍 Goal: Remote work + global career
